# newsletter_v2

국방·법률 분야 일간 뉴스 브리핑 자동 발송 프로그램.

매일 **06:30 이전에** 카카오톡(요약+링크)·텔레그램(전문)으로 뉴스레터를 발송합니다.
GitHub Actions에서 자동 실행되므로 PC를 켜둘 필요가 없습니다.

## 동작 방식

```
05:40 KST  GitHub Actions 실행
  → 구글 뉴스 RSS 47개 키워드 병렬 수집 (최근 28시간, 국내 언론)
  → 로컬 중복 제거 (URL/제목 유사도 클러스터링)
  → Claude API 1회 호출: 섹션 분류 + 의미 중복 제거 + 중요도 정렬
  → 과거 사례 포맷으로 조판, newsletters/YYYY-MM-DD.md 커밋
06:28 KST  카카오톡 + 텔레그램 발송
06:45 KST  백업 실행 (본 실행 실패 시에만 동작)
```
